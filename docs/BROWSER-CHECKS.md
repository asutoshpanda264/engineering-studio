**Connection-latency mismatch — FIXED for all 27 scenarios (decided: teach the concept, not the objectively fastest topology)**
- Root cause (recap): every scenario's `optimalSolution` was tuned/tested against 0ms connection latency, but the live Workshop always applies a 5ms-per-hop default (`DEFAULT_CONNECTION_LATENCY_MS`, now canonically in `src/lib/simulationDefaults.ts`, applied unconditionally by `workshopBridge.ts`'s `buildSimulationConfig`). Fixed every test harness to apply the real 5ms default (`scenarioScoring.test.ts`'s `run()`, `validator.test.ts`'s `runUnmodified()`) instead of loosening the live default to match fictional 0ms tuning.
- 24/27 scenarios needed no build changes — gate still passes, two with an honestly lower star count than documented (corrected in both the scenario header and the regression test): `adAuctionBidding` 2★→1★, `couponCodeRedemption` 2★→1★.
- The remaining 3 — `viralVideoComments`, `trendingProductSearch`, `globalLeaderboardUpdates` (the catalogue's "Cache + database-type, both required" scenarios) — turned out to be structurally broken at 5ms latency, not just mistuned: adding a Cache in front of the Database never improves p95 relative to skipping it, because p95 is a tail stat dominated by cache-miss traffic, and a miss pays the cache hop's network cost on top of the database hop's, for any hit rate this engine's key-distribution model produces. **Decision: keep cache+database-type as the taught `optimalSolution` anyway — the goal is the concept, not the objectively fastest topology — and retuned each scenario's p95 bar (26/30/26ms → 46/46/45ms respectively) so the shipped answer genuinely passes at real latency, with the unmodified starting scaffold still failing by a solid 3-6ms margin in every case.** A plain no-cache/NoSQL-only build also clears every gate in all three (and scores a higher composite — "legendary" territory) — left as a real, working, better-scoring alternative a student can discover, documented plainly in each header as a feature, not a bug.
- `npx vitest run`: 615/615 pass. `tsc`/`lint` both clean.
